# Cafe De Flora AI Assistant

AI-powered customer support chatbot for Cafe De Flora, Chanakyapuri, New Delhi.

## Project Goal

Build an AI chatbot that can:

- Answer questions about Cafe De Flora
- Provide menu information
- Answer questions about timings and location
- Help customers discover dishes
- Handle frequently asked questions
- Collect customer enquiries
- Provide human handoff when required

## Planned Technology

- Frontend: React
- Backend: FastAPI
- Database: Supabase
- AI: LLM API
- Knowledge Base: RAG
- Vector Search: Supabase pgvector
- Deployment: Cloud hosting

## Architecture

Customer
↓
React Chat Interface
↓
FastAPI Backend
↓
RAG / Knowledge Base
↓
AI Model
↓
Response
